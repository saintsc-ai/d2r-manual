# 변경 이력

## v4.4 (2026.08~)

- 레이아웃 관리자에서 화면영역을 우클릭해 좌표를 고치면 고친 값이 되돌아가던 문제 수정
- 설정 파일(INI)에서 값에 세미콜론(;)이 들어가면 뒤가 잘리던 문제 수정 (게임 방제·비밀번호·스크립트·메모 등)
- 비정상 종료 뒤 프로그램이 '이미 실행 중'이라며 켜지지 않던 문제 수정 (남은 PID 가 무관한 다른 프로그램의 것이 되어도 실행을 막고 있었음)
- 게임 창 제목을 서식으로 정할 수 있게 함 (%a 계정, %d 설명, %m 모드, %s 서버, %f 설정파일 조합 + 미리보기)
- 계정 편집 개편: '계정' 탭을 '기본 정보'로, 설명을 맨 위 필수 항목으로, 모드·설정파일·전리품 필터를 실행 옵션 탭으로 이동
- 토큰은 웹 토큰 방식일 때만 표시. 자동 토큰 생성 / 수동 토큰 생성 버튼으로 분리
- 레이아웃 관리자 툴바를 화면배치 줄과 화면영역 줄로 나눔. 모니터를 배치 형태보다 먼저 고르도록 변경
- 창 배치를 '화면배치'로 개편 — 계정마다 좌표를 들고 있던 것을 화면영역(자리) + 계정 할당으로 나눔
- 화면배치에 이름을 붙이고 개수 제한을 없앰 (환경설정과 레이아웃 관리자에서 이름으로 선택)
- 계정별 '실행 후 창 위치' 추가. 창 배열 방식에 '계정에 저장된 실행 후 창 위치' 추가
- 레이아웃 관리자에 화면영역 추가/삭제, 계정 할당(버튼·더블클릭·우클릭) 기능 추가
- 도움말에 변경 이력 보기 추가
- 계정 편집의 인증 방식을 라디오 버튼에서 선택 목록으로 변경
- 계정 편집에서 '키/조작 파일' 칸 제거 (캐릭터 단축키 편집기와 계정-캐릭터 연결에 같은 기능이 있음)
- 라이트 버전은 실행 후 창 위치만 사용하고 화면배치 단축키를 제외
- '창 배치를 바로 적용'이 편집 화면과 다른 자리로 창을 옮기던 문제 수정
- 계정 편집에서 '실행 중인 창 정보 가져오기'가 그림의 상자를 옮기지 않던 문제 수정
- 창 정보 탭의 좌표 칸이 창을 좁히면 겹쳐 보이던 문제 수정
- 라이트 버전(`d2r_lite.exe`) 추가 — 게임 창을 자동으로 조작하는 기능을 뺀 별도 프로그램
- 자동 업데이트 추가 (새 버전 확인 후 내려받아 교체, 정식판/라이트 각각)
- 테러존·우버 추적기를 게임 화면 위에 띄우는 오버레이 방식 추가
- 추적기 표시 방식을 끄기 / 팝업 창 / 게임 위 오버레이 세 가지로 정리
- 계정 생성·수정 창을 탭 세 장(계정 / 실행 옵션 / 창 정보)으로 개편
- 창 위치·크기를 화면 그림에서 끌어서 지정하는 편집기 추가
- 계정-캐릭터 연결 기능 추가 (계정 실행 시 그 캐릭터의 키 설정 복원)
- 파일 메뉴에 최근 연 파일 목록 추가, 새로 만들기 전 확인 절차 추가
- 계정 목록에 메트로 타일 보기 추가
- 플레이 통계 추가 (계정별 플레이 시간 집계)
- 레이아웃 관리자에 계정 목록 표시, 배치 형태 이름 다국어화
- 환경설정 고급 탭에 백엔드 API 서버 관리 기능 추가 (등록/수정/순서변경)
- 추적기 API 서버에 d2emu 직접 연결 지원, 폴백 서버 교체
- 스케줄 일시정지 토글 키를 고를 수 있게 변경 (기본 Scroll Lock)
- 하드코어 파티 루팅 허용 스크립트 추가
- 복사본으로 실행 여부를 환경설정에서 선택 가능
- 숫자 키패드를 일반 숫자키와 구분해 단축키에 사용 가능
- 이용 고지 동의 절차 추가
- MPQ 편집기 사용성 개선
- Caps Lock이 켜져 있거나 Shift를 누른 상태에서 단축키가 안 먹던 문제 수정
- 종료할 때 원본 실행파일이 삭제되던 문제 수정
- 파일 > 종료가 계정 저장 확인을 건너뛰던 문제 수정
- 업데이트 창에 실제와 다른 배포일이 표시되던 문제 수정
- 배틀넷 런처 로그인 스크립트 보정
