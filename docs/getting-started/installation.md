# 설치

## 시스템 요구사항

1. Windows 10 이상 (윈도우 10 23H2 권장)
   특정 버전 윈도우10, 11에서 GPU가속에서 프리징 현상이 발생합니다. 멀티로더 문제는 아니고 윈도우 버전 문제입니다.
2. Diablo II Resurrected 설치와 배틀넷 계정
   여러 게임 클라이언트를 실행하는 경우에는 실행하는 계임 클라이언트 개수 만큼 배틀넷 계정이 필요합니다.
3. 관리자 권한은 필요하지 않습니다
   예전에는 게임 프로세스의 핸들을 닫기 위해 관리자 권한으로 실행해야 했지만, 지금은 일반 권한으로 동작합니다. 자세한 내용은 아래 [권한에 대하여](#권한에-대하여)를 참고하세요.

## 설치 방법

### 압축 해제

다운로드한 파일의 압축을 풉니다.

### 실행 파일 위치

압축을 풀면 다음과 같은 파일들이 있습니다:

| 파일 | 설명 | 최근 빌드 |
|------|------|-----------|
| `d2r_gui.exe` | 메인 멀티 런처 | 2026-10-28 |
| `d2r_lite.exe` | 자동화 기능을 뺀 런처 | 2026-10-28 |
| `d2r_uber.exe` | 독립 실행 우버 트래커 | 2026-10-26 |
| `d2r_tz.exe` | 독립 실행 테러존 트래커 | 2026-10-26 |
| `d2r_helper.exe` | D2R 핸들 자동 정리 도구 | 2026-10-26 |

### d2r_gui

`d2r_gui.exe`는 메인 멀티 런처 프로그램입니다. 여러 배틀넷/스팀 계정으로 D2R 클라이언트를 동시에 실행하고 관리할 수 있습니다. 핸들 자동 정리, 스크립트 실행, 테러존/우버 트래커 등 모든 기능이 통합되어 있습니다.

### d2r_lite

`d2r_lite.exe`는 게임 창을 자동으로 조작하는 기능을 뺀 런처입니다. 계정 타일을 눌러 D2R을 띄우고, 창을 배치하고, 계정을 관리하는 것까지만 합니다. 스크립트 실행·스케줄·화면 읽기 기능은 프로그램 안에 들어 있지 않습니다.

로그인 방식은 웹 토큰, 명령줄, 스팀 세 가지를 지원합니다. 배틀넷 런처 방식만 제외했습니다 — 런처 창에 아이디와 비밀번호를 대신 입력해 주는 방식이라 자동 조작에 해당합니다.

!!! warning "안전을 보장하지 않습니다"
    계정 정지 사례가 자동화 때문인지 멀티 클라이언트 실행 자체 때문인지는 확인되지 않았습니다. 라이트 버전도 핸들 제거 실행은 동일하게 합니다. 말할 수 있는 것은 "게임 창을 자동으로 조작하지 않는다" 까지입니다.

`d2r_gui.exe`와 설정을 따로 보관하므로 두 프로그램을 같이 써도 서로의 설정을 건드리지 않습니다. 다만 계정 목록 파일(`default.dat`)은 공유하므로 같은 폴더에 두면 한 번에 하나만 실행됩니다.

### d2r_uber

`d2r_uber.exe`는 우버 디아블로(DClone) 진행 상황을 추적하는 독립 실행 프로그램입니다. `d2r_gui.exe` 없이 단독으로 사용할 수 있습니다.

### d2r_tz

`d2r_tz.exe`는 공포의 영역(Terror Zone) 정보를 추적하는 독립 실행 프로그램입니다. `d2r_gui.exe` 없이 단독으로 사용할 수 있습니다.

### d2r_helper

`d2r_helper.exe`는 D2R 프로세스의 핸들을 주기적으로 자동 정리하는 독립 실행 프로그램입니다.
멀티 클라이언트 실행 시 핸들 충돌을 방지하기 위해 사용합니다.
설정한 간격(1~10초)마다 자동으로 핸들을 닫으며, 트레이로 최소화하여 백그라운드에서 실행할 수 있습니다.
`d2r_gui.exe`에 핸들 자동 정리 기능이 포함되어 있으므로, 멀티 런처를 사용하는 경우에는 별도로 실행할 필요가 없습니다.

!!! note "백신 예외처리"
    파이썬으로 제작된 프로그램 특성상 일부 백신에서 악성코드로 오탐지할 수 있습니다.
    이는 패키징 프로그램(pyinstaller)으로 만든 실행파일들이 봇이나 악성코드 제작에 많이 사용되어 백신에서 오탐지하는 것입니다.
    **악성코드가 아니니** 백신 프로그램에서 예외 처리 후 사용하세요.

## 권한에 대하여

**이 프로그램은 관리자 권한 없이 실행됩니다.** 더블 클릭으로 바로 실행하면 되고, UAC(사용자 계정 컨트롤) 창은 뜨지 않습니다.

예전 버전은 게임 프로세스의 핸들을 닫기 위해 관리자 권한을 요구했습니다. 확인해 보니 그 작업은 일반 권한으로도 됩니다. 창 배치, 스크립트 실행, 화면 읽기도 마찬가지입니다.

### UAC 창이 뜨는 경우

다음 세 가지 작업에서만, 그것도 **대상 폴더가 `C:\Program Files` 안에 있을 때만** 권한을 올립니다.

| 작업 | 왜 필요한가 |
|------|-------------|
| 모드/스킨 설치 | 게임 폴더에 파일을 씁니다 |
| 모드/스킨 삭제 | 게임 폴더에서 파일을 지웁니다 |
| 자동 업데이트 | 자기 실행 파일을 새 버전으로 바꿉니다 |

먼저 일반 권한으로 시도해 보고 실패했을 때만 UAC 창을 띄웁니다. 스팀 라이브러리가 `D:` 같은 다른 드라이브에 있는 흔한 경우에는 UAC 창이 아예 뜨지 않습니다.

### D2R을 관리자 권한으로 실행하고 있다면

!!! warning "게임 쪽 '관리자 권한으로 실행' 체크를 해제하세요"
    D2R이 관리자 권한으로 떠 있으면 일반 권한인 이 프로그램이 그 창을 조작할 수 없습니다. 윈도우가 낮은 권한에서 높은 권한 창으로 가는 입력을 막기 때문입니다(UIPI).

    **입력이 조용히 무시되는 것**이 가장 곤란합니다. 오류가 나지 않고 성공한 것처럼 보이는데 게임 안에서는 아무 일도 일어나지 않습니다.

    D2R 바로가기나 `D2R.exe`에서 오른쪽 클릭 → **속성** → **호환성** 탭 → **관리자 권한으로 이 프로그램 실행** 체크를 해제하세요.

!!! warning "게임 파일 자체에 체크돼 있는 경우"
    D2R이 지금 떠 있지 않더라도, **`d2r.exe` 속성 > 호환성**에 '관리자 권한으로 이 프로그램 실행'이 체크돼 있으면 명령줄·웹 토큰 방식이 아예 실행되지 않습니다. 이 설정은 **파일 경로별**로 저장되므로 계정 일부만 막히기도 합니다.

    증상과 해결 방법은 [FAQ — 명령줄·웹 토큰 방식만 실행이 안 됩니다](../faq.md#q-명령줄웹-토큰-방식만-실행이-안-됩니다-배틀넷-런처로는-됩니다)를 참고하세요.

프로그램이 이 상황을 **실행 전에 감지**합니다. 손댈 수 없는 D2R 프로세스가 있으면 실행 버튼을 누를 때 안내 창이 뜨고, 거기서 **관리자 권한으로 다시 시작**을 고르면 이 프로그램을 관리자 권한으로 다시 띄웁니다. 메뉴에서도 언제든 고를 수 있습니다(**도움말 > 관리자 권한으로 다시 시작**). 이미 관리자 권한으로 떠 있을 때는 이 메뉴가 나오지 않습니다.

### 설정이 저장되는 위치

설정 폴더(`settings/`), 로그(`logs/`)는 실행 파일과 같은 폴더에 만들어집니다. 그 자리에 쓸 수 없으면(예: `C:\Program Files` 안에 두었을 때) **`%LOCALAPPDATA%\d2r_gui\`** 로 옮겨 쓰며, 처음 한 번 안내 창으로 알려 줍니다.

!!! tip "권장 위치"
    `D:\d2r_gui\` 처럼 **Program Files 밖의 폴더**에 두면 UAC 창을 볼 일이 거의 없습니다.
